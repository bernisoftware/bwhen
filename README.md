# bWhen

**When did I last…?** Log what you do now and then in one tap, ask out loud, and get reminded at the right time. iPhone, Apple Watch, Android and Wear OS.

bWhen is made by [Berni Software](https://www.bernisoftware.com.br). This repository holds the public pages: [support](https://bernisoftware.github.io/bwhen/) and [privacy policy](https://bernisoftware.github.io/bwhen/privacy.html). The app's source code is private.
